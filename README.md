# Pizza-Sales-Dashboard

An interactive Power BI dashboard that transforms raw pizza sales data into clear, actionable business intelligence

# Project Highlights

This dashboard delivers a comprehensive view of pizza sales performance through carefully crafted visuals and dynamic interactivity. Designed with business decision-making in mind, it highlights revenue trends, customer preferences, peak periods, and product performance — empowering quick identification of opportunities and optimization areas.

# Key Performance Indicators (KPIs)
- Total Revenue generated across the period
- Average Order Value  (AOV)
- Total Pizzas Sold & Total Orders Placed
- Average Pizzas per Order

# Core Visualizations & Insights
- Daily & Monthly Trends— Column + Line charts showing order volume patterns (peaks on weekends and specific months stand out clearly)
- Sales Distribution by Category & Size — Donut charts revealing dominance of Classic category and Large size pizzas
- Category Performance— Funnel view highlighting top contributors to total pizzas sold
- Top & Bottom Performers— Ranked bar charts for best/worst pizzas by revenue, quantity, and order count (with conditional formatting for instant visual impact)

#Interactivity Features
- Relative date range slicer for flexible time-based analysis
- Category & size filters with single-select/multi-select capability
- Navigation buttons for seamless flow between overview and detailed best/worst sellers page
- Cross-filtering enabled across all visuals for drill-down exploration
- Modern card visuals with conditional formatting and tooltips for enhanced readability

# Business Value Delivered
- Quickly spot peak ordering days and high-performing months to align staffing and promotions
- Understand customer size & category preferences to optimize inventory and menu planning
- Identify star performers (e.g., Thai Chicken leading in revenue) and underperformers to refine offerings and reduce waste
- Support data-driven decisions on marketing focus, pricing adjustments, and product development

# Tech Stack
- Power BI Desktop (advanced visuals, DAX measures, Power Query transformations)
- DAX for custom calculations & dynamic measures
- SQL Server (data source with validated base queries)
- Clean data modeling with proper relationships, hierarchies & sorting logic
